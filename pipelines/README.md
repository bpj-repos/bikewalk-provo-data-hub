# Processing libraries

- [crashes](crashes/README.md) is the Python ingestion, matching, normalization, enrichment and query library.
- `incident-map/` contains the JavaScript public-field and geographic validators used during historical map packaging.

- `traffic_stress/` reconciles citywide native bicycle ratings, topology, eligibility and coverage.

Operator commands live in [scripts](../scripts/README.md). Reviewed schemas and source definitions live in [data-definitions](../data-definitions/README.md).
